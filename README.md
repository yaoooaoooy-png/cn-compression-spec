# 中文压缩规范 · 使用说明

一套给 LLM 用的中文压缩规则。对象是 LLM 输出的中文，目标是提高信息密度、把结论放到该在的位置。

设计前提：压缩不是把文本变短，是删掉不含信息的句子。含信息的句子可以改短，但不得降低确定性、不得省掉目的与限定。

## 与 ASD-STE100 的区别

常有人把本规范当成「STE 中文版」。不是。两者目标相反。

STE（ASD-STE100，Issue 9，53 条规则、约 900 词受控词典）为飞机维修文档设计，目的是消除歧义，让不同母语背景的读者读出同一个意思。它会让文本**变长**：禁止省略、禁止模糊指代、要求补全省略成分。

本规范的目标是提高信息密度，所以它会让文本**变短**：删掉不含信息的整句。

| | STE | 本规范 |
|---|---|---|
| 目标 | 消除歧义 | 提高信息密度 |
| 文本长度 | 变长 | 变短 |
| 判据 | 二值：词在批准表内？句超 20 词？ | 判断：读者不知道会不会做错决定 |
| 执行前提 | 需持有受控词典 | 无需外部资产 |
| 覆盖层级 | 句层 | 句层、结构层、语体层 |
| 冲突裁决 | 无 | 五级优先级阶梯 |

**不采用 STE 的三项**

- 受控词典。受版权保护，且中文没有对应词表。
- 20 词与 25 词的句长上限。英文词数在中文无对应物，硬搬即假精确。本规范改用「一句只放一个判断」。
- 名词化强制改写。为机器翻译与非母语读者设计，中文收益接近零。

**沿用 STE 的四项**：同物同名、主动语态、句子完整通顺、不写废话。中文近义词密度远高于英文，同物同名在中文里比在英文里更需要执行。

**两者的定位不同。** STE 是行业标准，经过数十年跨行业验证，但它验证的是可读性，从来不打算让文本变短。本规范是从真实中文改稿案例归纳出来的规则集，验证范围限于已收录的对照样本。口语与网络用语两档的结论位置属推定，尚未经大规模检验。

## 目录

```
压缩规范/
├── SKILL.md              入口。含核心判据、优先级、快查清单，单独读也够用
├── README.md             本文件
├── LICENSE               MIT
└── references/
    ├── 完整规范.md         全部规则。唯一定义处，改规则只改这里
    ├── 样本库.md           四档语体对照样本 + 压缩过度反例
    └── 精简提示词.md       727 字，整段粘给外部 LLM
```

## 给别的 Agent 用，三种方式

**一、整目录克隆。** 把 `压缩规范/` 整个目录复制到对方的 skill 目录（如 `~/.workbuddy/skills/`、`~/.claude/skills/`）。对方读到 `SKILL.md` 即可生效，`references/` 按需读取。目录自包含，不引用任何外部文件。

**二、只给入口。** 只要 `SKILL.md`。核心判据、优先级阶梯、快查清单都在里面，够用。代价是没有四档语体表和样本库。

**三、只给提示词。** 只要 `references/精简提示词.md`，整段贴在对话开头。用于没有文件系统的场景（网页版 LLM）。代价是没有样本库，且与完整版存在漂移风险。

## 无依赖

不引用任何外部文件、不依赖特定平台。纯 Markdown。

## 改规则

改 `references/完整规范.md`，然后同步三处：
1. `SKILL.md` 的核心判据与快查清单
2. `references/精简提示词.md`
3. 本文的版本号

精简版只收永不改动的核心判据。改了判据就要三处一起改，否则会漂移。

## 规则来源与强度

规则不是从理论推出来的。主要来源是观察 LLM 中文输出的固有癖好，加上一份实证对照样本（组 1 与文末反例来自真实使用记录）。理论只用于两处：解释规则边界、裁决冲突。完整规范第十节列出了用到哪些概念，并注明未核对原始文献。

红线阈值（空转声明每千字 ≤2 处）是设定值，不是行业标准，可按实测调整。
